# 水印效果工作室（Watermark Effect Studio）

一款**纯前端、单文件、零服务器、完全本地离线运行**的多图层水印与材质滤镜工作台。双击 `index.html` 即可在浏览器中使用，无需安装任何软件或联网。

## 核心特性

- **多图层与文件夹管理**：支持导入多张透明黑素/贴图、添加横/竖排文字层、图层文件夹分组、选区与蒙版、套索与橡皮擦、历史撤销。
- **丰富的材质与光学滤镜库**：内置 71 款材质与光学效果，涵盖**填色与掐丝**、**亚克力**、**金属液态（M 系列）**、**玻璃透明（G 系列）**、**光影氛围（L 系列）**、**纹理描边（T 系列）**、**全屏叠加**及 **WebGL2 GPU 折光滤镜**。
- **多色分区填色与空洞工作台**：支持自动识别封闭空洞、6 色分区填色、底图自动取色、10% 柔边喷枪与硬边笔触手填。
- **灵活排版与高清导出**：支持单图自由变换、全屏铺满、整齐阵列与斜向错位平铺；支持导出原底图、模糊底图及纯透明底高清 PNG。
- **本地字体支持**：内置系统默认本地字体栈，并支持在文字层直接载入本地 `.ttf / .otf / .woff2` 字体文件（仅在浏览器内存中即时渲染）。

## 使用方式（支持断网 / 飞行模式自证）

1. 将本仓库中的 `index.html` 下载到本地电脑或手机。
2. **可选自证**：断开电脑网络或开启手机**飞行模式**。
3. 使用现代浏览器（Chrome / Edge / Safari / Firefox）直接打开 `index.html`，拖入底图与水印素材即可实时预览并导出高清成品。

## 关于隐私与原创说明

1. **纯前端本地离线运行（支持飞行模式自证）**：本工具基于纯前端 HTML5 Canvas / WebGL2 技术实现，无后端服务器、无数据库、无外部 CDN 与统计脚本、无任何图片上传行为。用户可在断网或开启手机飞行模式下直接运行验证。
2. **基于标准前端图像算法独立实现**：内置视觉与材质效果均基于标准图像处理、混合模式及光学渲染参数独立编写调校，不涉及生成式 AI，仅供学习交流与本地安全出图参考。
