# ✨ 水印效果工作室 · 多图层一键出图



一款基于纯前端图形学与 WebGL2 渲染的多图层水印效果制作工具。单 HTML 文件即可运行，**零生成式 AI、断网本地可用**，彻底杜绝底图与水印素材泄露风险。



## 🌟 核心亮点



* **🛡️ 纯本地图形学算法**：所有处理均在浏览器本地完成，不上传任何图片至服务器，断网状态下依然 100% 正常运行。

* **🎨 58 款精选质感效果库**：

  * **填色与掐丝**：亮镀、填色掐丝、渐变掐丝、金缕梦蝶、超厚实镀银、润雨等。

  * **折光 GPU 引擎**：内嵌 WebGL2 原生滤镜，支持水滴折射、铬化、毛玻璃缩放、缎面、提取线稿等。

  * **古风与日漫质感**：亚克力（164步立体高光与透光复刻）、羊脂玉、刺绣、立体宝石、哑光琉璃糖等。

* **🖌️ 6 色分区填色与珐琅工作台**：

  * 内置 39 套精选 6 色色卡（如童话茶话会、牡丹玉瓷、莫奈睡莲等），支持从底图一键自动提取 6 色。

  * 支持封闭空洞自动识别、油漆桶点填、10% 柔边喷枪双色晕染及防出界画笔。

* **📑 完整多图层工作流**：

  * 支持导入透明黑素/贴图、新建横排/竖排文字层、图层文件夹分组、蒙版与套索选区、自由排版及全屏平铺厚码。

  * 支持原底图、模糊底图（可调模糊度）、透明底三种模式切换与高清 PNG 导出。
