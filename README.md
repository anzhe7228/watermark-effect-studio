## 🎨 核心功能一览

- **95 款实时水印与光学质感效果**
  - **古风质感**：冰感玉石（双层水滴折射 + 细密冰裂纹 + 鎏白细掐丝 / 温润无掐丝切换 + 4 套玉石色卡）、琉璃浮雕、金箔印章等。
  - **稿风 / 古风·稿风**：仿 PS 立体质感（古风刺绣丝缎 / 稿风通透琉璃双模式 9 阶管线）、立体浮雕高光等。
  - **日漫贴纸**：流行双圈贴纸效果（白芯 A·细深边 / 白芯 B·双圈贴纸、第三重封边圈、亮白防发灰保护）等 31 款日漫常用风格。
  - **折光 GPU 滤镜**：实时 WebGL 光学玻璃折射、水波棱镜、色散炫光，以及 **「纯净颜色(白)」**（白底贴图无白边去底转全透明）与 **「纯净颜色(灰度)」**（一键提取纯净透明遮罩并原图超清固化）。
  - **全屏防盗铺满 & 百搭基础款**：斜向阵列防盗网格、自适应间距平铺等 21 款全屏守护方案。
- **智能水印填色工作区**
  - 支持单色、多段渐变、画笔自由涂抹分色，内置多套精选 6 色预设方案（红笺琉璃、粉蓝银霜、暖杏茶紫、糖彩绯梦、森野风吟、晴翠丹霞等）。
- **多图层编组与线稿提取**
  - 支持多图层独立滤镜叠加、文件夹编组、套索局部选区改色/擦除、黑素/白底图一键 **「提取线稿」** 并固化为透明图层。
  - 支持 **「📐 按当前图层 / 底图尺寸切换画布」**，非正比横图、长竖图一键 1:1 匹配画布尺寸。
- **防闪退本地自动存盘与显存优化**
  - 内置纯本地 `IndexedDB` 自动草稿快照，意外闪退、内存不足重加载或误关页面重进时，顶部支持 **「一键恢复全部图层」**；历史撤销栈自动压缩休眠，大幅降低手机与平板浏览器内存占用。
