关于隐私与原创说明

1. 纯前端本地离线运行（支持飞行模式自证）
本工具为单文件纯前端网页应用，基于 HTML5 Canvas 与 WebGL2 技术在本地浏览器内完成全部渲染与导出。无后端服务器、无数据库、无任何外部 CDN 请求与图片上传行为。您可断开网络或开启手机飞行模式直接打开本页面验证。
2. 基于标准前端图像算法独立实现
内置的填色、掐丝、亚克力、折光、浮雕、全屏叠加及各类材质滤镜效果，均基于标准前端图像处理、混合模式与光学渲染参数独立编写调校，不涉及生成式 AI，仅供学习交流与本地安全出图参考。
字体说明：内置字体仅调用系统默认本地字体栈，同时支持用户自行导入本地 .ttf / .otf / .woff2 字体文件在浏览器内存中即时渲染。
📖 新手使用说明
① 界面怎么分：左边竖条是工具（移动 V / 套索 L / 魔棒 W / 橡皮 E / 填色 K / 吸管 I / 抓手 H / 撤销 / 清空图层 / 对比 / 适应窗口 / ? 说明）；中间是画布；右边三个页签依次是「图层与全屏」「效果」「画布与导出」；底部一行是缩放、大画布、分区数。
② 导入素材：右面板「导入黑素/贴图」可一次选多张，也可以直接把图片拖进画布；「添加文字层」生成文字。素材是透明黑素最省事，白底图可先切「透明底」查看效果。
③ 画布底图（已放入图层列表）：「🖼️ 画布底图」就在图层列表里，可以直接点选！支持 原底图 / 模糊底图 / 透明底 切换、调模糊度与染色、点右侧 👁 显隐，也可以像普通图层一样用 ↑ / ↓ 自由调上下顺序，或点 ⧉ 复制拷贝；长图会自动适配画布不裁切。
④ 图层快捷三联栏：图层列表下方三个高频按钮——✦ 克隆模糊层（选中水印或底图，一键克隆独立高斯模糊层，顺序随时 ↑/↓ 调，拿橡皮可局部擦出清晰主体）；✂️ 剪贴蒙版（向下剪辑，让当前层只显示在正下方图层轮廓内，再点取消）；✨ 烘焙效果（把当前特效固化写入图层像素，烘焙后点「✨ 叠新效果」直接去「效果」页选新样式即可叠加第二层，支持 Ctrl+Z 撤销）。
⑤ 图层管理、横竖拉伸与套索拆层：支持建文件夹、合并、上移下移、复制、删除；横竖插画尺寸对不上时，直接拉 横向拉伸 X / 纵向拉伸 Y、拖画布四边中点或点 按宽适配 / 按高适配 / 铺满拉伸；用套索 (L) 或魔棒 (W) 圈选局部后，可点 ✂️ 剪切并移动 或 ⧉ 复制为新层 直接拆出独立图层拖动；Ctrl+Z 随时撤销。
⑥ 吸色与 6 色分区填色：选吸管（I）点底图任意位置可直接吸到色卡/渐变/阴影颜色；「分区：N」为识别出的封闭色块数，填色工具支持点填色块、10% 柔边喷枪、硬边笔、擦填色与开关空洞。
⑦ 效果与立体投影：「效果」页支持全部核心样式与 52 款预设，展开「立体与发光增强」可独立精调 阴影透明度、阴影距离、阴影大小（模糊半径） 及 自定义阴影颜色。
⑧ 导出、批量套底图与离线：右上「一键导出 PNG」按当前底图模式高清出图；在「画布与导出」页可使用 📦 批量套底图（同水印一次套多张底图，支持每张自动按底图取色或锁定当前配色，电脑一键打包 ZIP、手机画廊长按存相册）；「存离线版」可将工作室存为本地单文件。
⑨ 手机端 & 长按文字说明：画布与面板中间横线可上下拖调比例，点「大画布 ▾」可收起面板；任意按钮长按约半秒都会弹出它的用途文字说明，且不会误触执行。
🛡️ 全程在你自己浏览器里计算，图片不上传服务器、断网也能用，没有底图泄漏这回事。
